Pawservation AI Chat Agent

A Claude Haiku 5.5 booking agent on web chat and WhatsApp, with a human approving every request and nearly all AI-made requests approved as submitted.

Live

Clients book in plain language on web chat or WhatsApp. The agent proposes, the client confirms, and the business owner approves each request in one tap. I designed it on the assumption that a prompt injection eventually lands, so a compromised turn can propose a change but cannot execute one, and conversation history is rebuilt on the server so a client cannot forge a tool result such as a $0 quote.

  • Shipped a customer-facing Claude Haiku 5.5 agent (Vercel AI SDK, 15 tools) on web chat and WhatsApp, plus a remote MCP server that shares the same tool definitions.
  • Designed human-in-the-loop booking through one channel-agnostic approval service. Every write sits behind a confirmation card and a single-use token claimed atomically in the database (20 concurrent redemptions produce one winner), and the owner approves in one tap from an admin queue or WhatsApp.
  • Layered cost controls (20 messages/hour, 50k tokens/day, per-user and global USD caps) and a circuit breaker at the agent layer, so it still protects downstream tools when the model is the thing misbehaving.
  • Cut AI cost on three fronts: eval-run cost 79% with cached prompt blocks (about 95% of input tokens from cache), per-turn cost about 8x by moving to a smaller model with no measured quality loss, and model choice from a 16-config eval matrix and a benchmark against 8 open-weight models, where 3 broke a booking-safety rule.
  • Moved rules the model kept missing into the server: same-day booking enforcement, date and night-count checks on every reply, and server-built booking previews (44 of 44 previewed correctly), still applied only on the client's tap.
  • Raised the pass rate from 85% to 93% across 1,251 eval cases (4 channels, 8 business-rule setups) by triaging 292 failures into 22 root causes and moving date parsing into deterministic code.
  • Built a database-state grading harness that judges agents on rows written, not reply text, catching 41 of 41 injected defects versus 4 before and exposing three change-booking bugs fixed within a day.
  • Gave the owner a 9-tool WhatsApp admin agent for requests, bookings, payments, and extra charges, each change a one-tap preview with an audit row, and added an emailed human hand-off on all 3 AI channels.

Pawservation MCP Server

A standards-compliant Model Context Protocol server with OAuth 2.1 + PKCE, stateless on Workers V8.

Spec-strict

Clients book from their own Claude, Claude Desktop, Cursor, or any spec-compliant client. The MCP SDK supplies the protocol layer. I hand-built the OAuth 2.1 + PKCE authorization server, stateless across the Workers V8 fleet. MCP Auth Kit (below) is the open-source version of the auth and safety layer.

  • Built the MCP booking server (@modelcontextprotocol/sdk v1.x, Streamable HTTP) with 16 tools: the chat agent's 15 shared definitions plus a confirm tool, from one source of truth.
